ESP32-S3 无线测试平台

一个跑在单块 ESP32-S3 上的独立测试平台，一半做 WiFi 监听，一半做 BLE 广播。 不接电脑也能用 —— 插上任意 USB 充电器，连它的热点就能打开网页界面。

  • 自带热点的 WiFi 监听：起一个开放式 AP，跑真实的 DHCP 与 DNS 劫持，被动抓取接入设备的 802.11 帧
  • 解码全在设备端完成：DNS 查询、HTTP Host、TLS SNI、DHCP 租约、ARP、ICMP、关联过程，不需要上位机
  • BLE 近场配对广播器：按 300ms 一发轮流播 Apple Continuity 广播模板，带管理员开关和硬性 60 秒自动关闭
  • 发射功率可调：3 / 0 / 6 / 9 / −3 / −9 dBm 实时切换，默认 3 dBm；串口还能开 verbose 打印每一个发出的包
  • 双语管理面板：首次访问跟随浏览器语言，EN / 中文 可切换并记忆；另有 JSON 接口与可下载的日志
  • 整条工具链自带：仓库内置 arduino-cli、编译上传脚本、PC 端监听工具和一整套测试脚本

Barbeque's Delight

把 MaoMao 的 Farmer's Delight 附属模组《Barbeque's Delight》从 Minecraft 1.20.1 / Fabric / Yarn 移植到 Minecraft 26.1。玩法、机制与贴图与原版 1.1.0 保持一致 —— 这是移植，不是重做。

  • 烤架（Grill）：左右两半各自独立。空手右键放食材，潜行右键翻面 —— 但只有至少半熟时才接受翻面
  • 翻面即成品，不翻就烤糊：翻面后烤成配方产物，放着不管会变成 burnt_food
  • 必须加热：下方需要热源（比如营火）。烧烤配方优先于原版营火配方，后者作为兜底（cookingTime − 200）
  • 食材盆（Ingredients Basin）：同样分两半，右键存放食材，主手持木棍、副手可加配料，右键串成串
  • 内容规模：3 种方块（烤架 / 食材盆 / 托盘）、9 种生串、9 种烤串、6 种调味粉与酱料，外加卷饼、三明治、石锅拌饭与烤肉村民交易
  • 一个 jar 覆盖三个版本："minecraft": "~26.1" 在 Fabric 语义下等于 [26.1, 26.2)，正好覆盖 26.1 / 26.1.1 / 26.1.2

Cultural Delights

NCP Bails 的 Farmer's Delight 附属模组《Cultural Delights》—— 一个把世界各地风味食物做进 Minecraft 的食物系统。这个仓库的工作是把它 适配到 Minecraft 1.21.1，后续又追加了一个 26.1 Fabric 分支。

  • 四种作物 + 一棵树：玉米、黄瓜、茄子（含白茄子）可以种，牛油果是完整树木 —— 原木、树叶、树苗、果核、盆栽一应俱全
  • 72 个物品模型：牛油果吐司、墨西哥卷、塔可、恩潘纳达、加州卷、味噌汤、石锅拌饭、爆米花、腌黄瓜、烟熏系列……
  • 世界生成：野生的玉米、黄瓜与茄子会自然生成在地图里，配套的 Configured / Placed Feature 与生物群系修饰器都写好了
  • 数据生成：DataGenerators 负责模型、配方、战利品表与数据包的自动产出，改一处不用手改十份 JSON
  • 1.21.1 适配内容：NeoForge 21.1.219 + Parchment 2024.11.17 映射，mod_version 0.17.8
  • 额外分支：26.1-fabric 分支上有一个提交 —— Port to Minecraft 26.1 (Fabric)，把整个模组再搬到新版本
